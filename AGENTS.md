# BYD Split — Seagull

Рабочая ветка: `seagull`. База: `main`, коммит `147a17c` (0.9.1).

Целевой автомобиль — BYD Seagull, Android 9 (API 28), DiLink 2,
штатный экран 10,1 дюйма. На проверенном автомобиле измерены
1280×720 и 160 dpi (docs/firmware/di2-diplus.md). На другой комплектации
проверять параметры и системные отступы заново, не определять по диагонали.

Основные направления: адаптация интерфейса и ADB-помощников.
Сохранять исходный дизайн UI7 и изометрическую схему автомобиля.
Для Seagull убрать двигатель, бак и гибридные показатели, сохранив
батарею, электропривод, компас и компоновку 1:2.
Владелец подтвердил отсутствие датчиков шин: не возвращать подписи
давления/температуры шин и их линии; геометрию автомобиля сохранять. Владелец явно
отклонил замену схемы видом сверху и полную перестройку панели.
На реальном DiLink 2 подтверждены телеметрия и отображение Навигатора;
длительные проверки в поездке и после перезагрузки ещё не завершены.
Локальные OTA, распаковки и декомпиляция: `tmp/ota-di2`, `tmp/ota-di5`.
Находки, каталог SDK и происхождение ресурсов: `docs/firmware/README.md`.
Не объявлять общий кузов из многомодельной OTA точной моделью Seagull.
Владелец выбрал похожий на Seagull силуэт `newenergy_flow_car_img_cross`:
использовать его дневную/ночную версии с соответствующими тенями.
Тема авто следует Android uiMode, как штатный Di2 SystemUI; ручной выбор
локален для лаунчера. Не переносить Binder-адреса из Di5 в Di2 без проверки.
Не переносить предположения о DiLink 5 / Android 12 и телеметрии
Song L DM-i на Seagull без проверки. Seagull — электромобиль:
гибридные функции требуют отдельного рассмотрения.

Полезные изменения из исходного проекта переносить выборочно через
`git cherry-pick`, проверяя совместимость с API 28. Не сливать всю
`main` автоматически. Сохранять происхождение переносимых коммитов (`-x`).

Сохраняются исходные applicationId и механизм обновления.
Текущий выпуск: 0.9.2-seagull-alpha.9, versionCode 45.
Текущая тестовая сборка: 0.9.2-seagull-alpha.9, versionCode 45.
Seagull публикуется как prerelease, без замены latest стабильного Song.
Канал обновлений Seagull изолирован тегами seagull-v*: APK BYD-Split-Seagull-*.apk.
Сборки выпусков делать из ветки seagull и подписывать тем же ключом, что
у установленного приложения. См. docs/SEAGULL-UPDATES.md.
Общий ключ для двух ПК настраивается по docs/SEAGULL-SIGNING.md.
По запросу владельца создан постоянный релизный ключ (RSA3072), публичный
сертификат в signing/seagull-release-cert.pem; приватный ключ вне Git.
Он отличается от ключа alpha.4 на Mac: обновление старого APK поверх
невозможно без отдельной миграции. На проверенной машине установлен постоянный ключ; alpha.6–alpha.9
успешно обновлялись поверх alpha.5 с сохранением настроек.

Сборка: JDK 17, Android SDK 35, Gradle Wrapper 8.9.
Проверки: `./gradlew assembleDebug lintDebug testDebugUnitTest`,
а также `./tools/test_logic.sh` в POSIX-окружении.
В Windows использовать `gradlew.bat`; локальный SDK задавать в
игнорируемом `local.properties`. Не коммитить локальные пути и ключи.

Перед продолжением на другом ПК прочитать `docs/HANDOFF-SEAGULL.md`.
Владелец отложил исправление необновления левой панели при переключении
на Музыку до проверки на настоящем DiLink 2. Не менять это поведение без
новых результатов или запроса владельца.

План адаптации и исходные ограничения: `docs/SEAGULL.md`.
Эмулятор Android 9: `tools/seagull-emulator.ps1`, параметры и ограничения:
`docs/SEAGULL-EMULATOR.md`.


README.md — пользовательское описание Seagull. Не добавлять туда инструкции
для ИИ, локальные пути, команды диагностики и процесс сборки. Общая документация
разработки — docs/DEVELOPMENT.md, передача контекста — docs/HANDOFF-SEAGULL.md.
Не использовать скриншоты Song/DM-i для Seagull. Не представлять изменения
рабочей ветки как уже опубликованные в alpha.4.

Для будущих публикаций и установки на тестовый стенд использовать постоянный
релизный сертификат signing/seagull-release-cert.sha256 и release APK.
Подготовка: tools/build_release.sh; публикация: tools/publish_release.sh.
Не загружать в Releases CI debug APK, не перезаписывать alpha.4 новым ключом.
Перед сборкой сверять origin/seagull: на другом ПК могут быть новые доработки.
