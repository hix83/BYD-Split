# BYD Split — Seagull

Рабочая ветка: `seagull`. База: `main`, коммит `147a17c` (0.9.1).

Целевой автомобиль — BYD Seagull, Android 9 (API 28), DiLink 2,
штатный экран 10,1 дюйма (уточнено владельцем). Точное разрешение, плотность и системные отступы
нужно получить с автомобиля; не определять их по диагонали.

Основные направления: адаптация интерфейса и ADB-помощников.
Поддержка DiLink 2 пока не подтверждена на устройстве.
Не переносить предположения о DiLink 5 / Android 12 и телеметрии
Song L DM-i на Seagull без проверки. Seagull — электромобиль:
гибридные функции требуют отдельного рассмотрения.

Полезные изменения из исходного проекта переносить выборочно через
`git cherry-pick`, проверяя совместимость с API 28. Не сливать всю
`main` автоматически. Сохранять происхождение переносимых коммитов (`-x`).

Пока сохраняются исходные applicationId, версии и механизм обновления.
До установки на автомобиль отдельно решить вопрос идентификатора пакета,
подписи и канала обновлений: текущий канал относится к исходному проекту.

Сборка: JDK 17, Android SDK 35, Gradle Wrapper 8.9.
Проверки: `./gradlew assembleDebug lintDebug testDebugUnitTest`,
а также `./tools/test_logic.sh` в POSIX-окружении.
В Windows использовать `gradlew.bat`; локальный SDK задавать в
игнорируемом `local.properties`. Не коммитить локальные пути и ключи.

План адаптации и исходные ограничения: `docs/SEAGULL.md`.
Эмулятор Android 9: `tools/seagull-emulator.ps1`, параметры и ограничения:
`docs/SEAGULL-EMULATOR.md`.
