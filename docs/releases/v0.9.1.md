# BYD Split 0.9.1

В настройки добавлены обновления из GitHub Releases: автоматическая проверка раз в сутки (отключается) и кнопка ручной проверки. Новая версия загружается по HTTPS, проверяются контрольная сумма GitHub при наличии, имя пакета, versionCode и подпись установленного приложения. Установка выполняется системным установщиком после подтверждения; настройки сохраняются. При первом обновлении Android может запросить разрешение на установку для BYD Split.

Также добавлен трек Яндекс Музыки / Яндекс Навигатора в штатную музыкальную карточку приборки: название, исполнитель при поддержке прошивки, состояние и прогресс. По умолчанию выключено, требуется доступ к уведомлениям и ADB. Проверка отображения на физической приборке ещё не проведена. Обложки штатный провайдер не предоставляет.

Исправлены Snowfield и режимы потоков DM-i по текущей телеметрии. Телефонный экран отложен, шестая кнопка скрыта.

Пакет ru.logunov.bydsplit, versionCode 36, versionName 0.9.1. Подпись совместима с опубликованной 0.9.0. APK подписан существующим ключом Android Debug для сохранения совместимости экспериментальных выпусков.
