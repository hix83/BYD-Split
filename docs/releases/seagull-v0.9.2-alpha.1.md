# BYD Split — Seagull 0.9.2-alpha.1

Предварительный выпуск для BYD Seagull, Android 9 / DiLink 2. Проверен в эмуляторе API 28; проверка на автомобиле ещё предстоит.

- Сохранена исходная изометрическая схема UI7, убраны ДВС и гибридные показатели. Добавлены выбранный владельцем силуэт из Di5, дневная/ночная палитры и следование Android uiMode.
- Добавлены чтение данных и управление климатом через SDK из Di2 OTA, проверка параметров и чтение результата команды. Доступ к сервисам автомобиля пока не подтверждён на настоящем устройстве.
- Для API 28 переработаны виртуальные дисплеи и передача ввода через shell-помощник. Проверены обе панели: нажатия, свайпы, мультитач, координаты, cancel и «Назад».
- Установлены и проверены в эмуляторе Яндекс Музыка и Навигатор. Их APK не входят в релиз.
- Значок Song заменён на чайку, увеличены шрифты, проверена компоновка с логическим разрешением 1366×768 при 160 dpi.

**Известная проблема:** владелец сообщил о необновлении левой панели при переключении на Музыку. По его просьбе дальнейшие изменения отложены до проверки на настоящем DiLink 2. Подтверждения штатного разрешения и плотности также ждём с автомобиля.

Пакет `ru.logunov.bydsplit`, версия `0.9.2-seagull-alpha.1`, versionCode `37`. APK подписан текущим ключом Android Debug; это экспериментальный выпуск. Стабильный latest-релиз Song остаётся отдельным. Автообновление лаунчера пока использует исходный стабильный канал, поэтому этот prerelease устанавливается вручную.

Проверки: assembleDebug, assembleDebugAndroidTest, lintDebug, отдельные тесты логики; instrumentation на Android 9 успешно выполнен для driver и far до изменения только значка/шрифтов. testDebugUnitTest не содержит JUnit-тестов (NO-SOURCE).

Инструкция переноса и текст для нового чата: [docs/HANDOFF-SEAGULL.md](https://github.com/hix83/BYD-Split/blob/seagull/docs/HANDOFF-SEAGULL.md).
