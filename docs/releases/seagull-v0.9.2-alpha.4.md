# BYD Split · Seagull 0.9.2-alpha.4

Предварительный выпуск для BYD Seagull с DiLink 2 / Android 9.
Версия приложения: `0.9.2-seagull-alpha.4`, versionCode `40`.

## Изменения

- Восстановлено получение телеметрии через локальный Di+: скорость, SOC,
  обороты электропривода, мощность батареи и параметры климата. SOH,
  температуры батареи и напряжение бортсети дополняются данными Di2.
- Кнопка климата открывает штатный климат; значок показывает интенсивность
  вентилятора и направление обдува. Целевая температура отображается
  над напряжением бортсети. Показания отсутствующих датчиков шин скрыты.
- Исправлены падения панели автомобиля и экрана техники при неполных данных.
- Исправлена потеря слоя карты Яндекс Навигатора: задача приложения
  активируется внутри области, включая возврат с экрана техники/батареи.
- Виртуальные дисплеи сохраняют идентификаторы при пересоздании областей.
  Полноэкранный режим встроенных приложений не требует возврата фокуса лаунчеру.
- Добавлен переключатель «Автозапуск DiLink Remote ADB» в настройках поведения.
  Контроль восстанавливает отсутствующий процесс и добавляет Remote ADB
  в исключения DuraSpeed, который закрывал его при высокой загрузке CPU.
- Обновления Seagull выбираются только из собственного канала `seagull-v*`.
  Выпуски основной версии для Song не предлагаются.

## Проверки и ограничения

Сборка, lint и набор тестов логики прошли. На эмуляторе Android 9 проверены
ввод в областях, сохранение дисплеев, отображение при отсутствующей телеметрии,
активность встроенного приложения и восстановление полноэкранной настройки.
На реальном DiLink 2 подтверждены телеметрия, восстановление карты Навигатора,
возврат с экрана техники и сохранение ADB-туннеля после исключения DuraSpeed.
Длительный прогон в поездке и проверка после перезагрузки ещё не завершены.

Для телеметрии необходим работающий локальный источник Di+ и авторизованный
ADB-доступ. Управление подогревами через Di2 SDK пока не подтверждено.
Настройка контроля ADB Remote по умолчанию выключена.

APK подписан тем же локальным ключом, что и текущая сборка на автомобиле
владельца. Обновление поверх сборок с другой подписью Android отклонит.
Ключи и приватные данные в репозиторий не включены.
