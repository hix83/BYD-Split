# BYD Split 0.9.0 — UI7 и состояние автомобиля

Обновление автомобильной панели для BYD DiLink 5 / Android 12, проверенное
на Song L DM-i. Служебная область объединяет автомобиль, DM-i, давление шин,
заполнение батареи и бака, а выбранное приложение сохраняется во второй области.

## Что добавлено

- Оформление UI7, единый стиль кнопок, компас и системный звук нажатий.
- SOH, температура батареи, уровень топлива, напряжение бортовой сети,
  обороты двигателя и электропривода. Неизвестные значения показаны прочерками.
- Подробный экран батареи по нажатию SOH и экран техники по кнопке с инструментами;
  панели появляются с анимацией без перезапуска встроенного приложения.
- Конструктор правил: несколько условий, «все/любое», температура салона и улицы,
  въезд в геозону, подогрев/вентиляция сидений, подогрев руля и открытие камеры.
  Выбор уровней, запуск один раз, таймер выключения, журнал и отдельное окно тестов.
- Выбор геозон на карте с настройкой радиуса и компактный список правил.
- Живой штатный значок климата: семь ступеней вентилятора и направления обдува.
- Открытие основной страницы кондиционера, кнопка техники и скрытие клавиатуры
  по «Назад» без сворачивания BYD Split.
- Перенос входящего звонка MAX во встроенную область с переключением панели.

## Проверено

- Сборка APK и автоматические проверки логики батареи, телеметрии, DM-i,
  климатического значка, правил и обработки звонков MAX.
- На машине: чтение телеметрии, две ступени вентилятора/обдув ног, открытие
  панелей и скрытие Яндекс Клавиатуры кнопкой «Назад».
- В эмуляторе: список с 14 правилами, прокрутка и закреплённые кнопки.

## Известные ограничения

- Температура охлаждающей жидкости ДВС пока не читается на проверенной машине.
- Часть дополнительных датчиков зависит от модели и прошивки; неподтверждённые
  адреса температур моторов/инверторов и заднего привода не выдаются за реальные данные.
- Реальное исполнение команд подогрева/вентиляции и геозон требует проверки;
  длительный прогон на автомобиле ещё не выполнен.
- MAX может кратко появляться на весь экран до переноса. Прошивка не даёт
  приложению необходимых прав для гарантированного перехвата до показа.

## Установка

APK подписан текущим отладочным ключом проекта, как и установленная тестовая версия.
Это сборка для тестирования; отдельная производственная подпись не настроена.
Обновлять поверх совместимой подписи без удаления данных: `adb -s SERIAL install -r APK`.
Для установки с настройкой ADB-помощников используйте `tools/install_and_start.sh SERIAL`
из этого тега (потребуются Android SDK и JDK 17). Обнаружение устройства не заменяет
настройку ADB-доступа приложения и системных разрешений помощников.
