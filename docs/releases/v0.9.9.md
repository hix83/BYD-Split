# BYD Split 0.9.9 · Song

Обновление исправляет возврат к приложениям с динамической панели.

- Повторное нажатие возвращает существующую задачу приложения в область 2/3.
- Поиск учитывает исходное приложение задачи, даже когда поверх него открыто другое окно.
- При ошибке ADB Split переподключается и повторяет попытку восстановления. Ошибка поиска больше не считается отсутствием задачи и не ведёт к слепому запуску второго экземпляра.
- Если задача приложения уже завершена, Split запускает приложение заново.
- При сохраняющейся ошибке можно повторно нажать кнопку приложения; сообщение больше не требует перезапуска Split.

На эмуляторе Android 12 проверены повторные нажатия, переход A → B → A, возврат задачи с основного дисплея, обрыв соединения ADB и принудительное завершение приложения. Проверка именно на реальной Song с приложением, на котором замечена проблема, ещё нужна.

Для обновления поверх 0.9.8 APK должен быть подписан прежним ключом Song. Версия 0.9.9, versionCode 44.
