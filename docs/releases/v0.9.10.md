# BYD Split 0.9.10 · Song

Отчёты диагностики Telegram теперь можно отправлять через свой HTTPS-шлюз или обычный прокси — удобно, когда прямое соединение с Telegram из машины недоступно.

## Новое в «Интеграциях»

Для Telegram доступны четыре способа подключения:

- **Напрямую / VPN на ГУ** — используется подключение головного устройства. Если VPN уже настроен на нём, отдельный шлюз не нужен.
- **HTTPS-шлюз Split** — адрес своего сервера и ключ доступа. Можно подключить собственный экземпляр шлюза.
- **HTTP-прокси** — адрес и порт, при необходимости логин и пароль.
- **SOCKS5-прокси** — адрес и порт с необязательной авторизацией. Это обычный SOCKS5, не MTProto-прокси из Telegram.

Выбранное соединение применяется только к Telegram внутри Split. Настройки хранятся в зашифрованном виде. Приложение различает ошибки ключа шлюза, авторизации прокси и соединения — проще понять, что нужно поправить.

**Как подключить:** Настройки → Интеграции → Настроить соединение → выберите режим и сохраните. Затем проверьте токен своего бота и завершите привязку чата. Адрес и ключ шлюза настраиваются отдельно: личные ключи в APK не включены.

## Отчёты и работа в фоне

Короткие отчёты отправляются текстом, длинные — полным TXT-файлом. При неудачной отправке отчёт остаётся в приложении для повторной отправки вручную. Новые периодические опросы, фоновые сканеры и постоянные сетевые службы не добавлялись; активный запрос отменяется при уходе со страницы или переходе машины в сон.

Для собственного сервера в исходниках есть Docker Compose и инструкция настройки в aaPanel. Доступно ведение журнала только с метаданными запросов и ежедневной ротацией архивов за 7 дней — без ключей, токенов и содержимого отчётов.

Все исправления возврата приложений из **0.9.9** сохранены. Экспериментальная диагностика **Denza в выпуск не включена**. Это обновление только для **Song**; релизы Чайки не менялись.

## Установка и проверки

Скачайте **BYD-Split-0.9.10.apk** либо проверьте обновления в приложении. Установка поверх прежней Song-версии с сохранением настроек: подпись прежняя, удалять приложение не нужно.

Версия **0.9.10**, код **45**. Проверены сборка, lint, тесты логики и шлюза, транспортные сценарии в эмуляторе Android 12. Проверка HTTPS-шлюза выполнялась с тестовым недействительным токеном; доставка реального отчёта вашим ботом из машины пока не подтверждена.
