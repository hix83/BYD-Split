# BYD Split · Seagull 0.9.2-alpha.5

Предварительный выпуск для BYD Seagull, DiLink 2 / Android 9.
Версия APK `0.9.2-seagull-alpha.5`, versionCode `41`.

## Важно при переходе с alpha.4

Этот выпуск впервые подписан постоянным релизным ключом Seagull.
Он отличается от подписи опубликованной alpha.4: Android не разрешит
установить alpha.5 поверх неё. Требуется отдельный перенос настроек
и переустановка; удаление приложения удаляет его данные.
Приложение не удаляется автоматически. После перехода следующие выпуски
с тем же ключом смогут обновляться обычным способом.

SHA-256 сертификата:
`2212fb7e72390b5119205bc78228060714ff110f10dbfdd4030281d41d7d7b2c`.

## Что изменилось

- Помощники ADB восстанавливаются при позднем появлении подключения,
  без перезапуска лаунчера и перестройки работающих панелей.
- Под температурой батареи показан статус ADB: предупреждение при отсутствии
  связи, зелёная галочка при подключении. Текст об успехе плавно исчезает.
- Настройки открываются внутри правой области, аналогично экрану батареи
  и техники; приложение за ними сохраняется и возвращается по кнопке «Назад».
- Разделы настроек: экран, автомобиль, запуск и ADB, камера, места,
  автоматизации и обновления. Обновлены дневная и ночная темы настроек.
- Подключён постоянный ключ для сборок на разных ПК. Скрипты установки
  и публикации проверяют релизную подпись; debug APK в публикацию не проходит.
- README обновлён для Seagull с актуальными скриншотами и ограничениями.

Сохранены телеметрия Di+, дополнение SOH/температур/напряжения через Di2,
исправления карты Навигатора, контроль ADB Remote и отдельный канал Seagull.

## Проверки

Сборка release, lint и тесты логики прошли. Новый сертификат APK проверен.
В разработке на эмуляторе Android 9 проверены задержка подключения ADB,
индикация связи, разделы настроек, дневная/ночная темы и возврат к приложению.
Новые изменения этого выпуска после холодного запуска реального DiLink 2
ещё требуют проверки. Длительные испытания в поездке продолжаются.

Для телеметрии нужен работающий Di+ и авторизованный ADB. Реальные команды
подогревов через Di2 SDK пока не подтверждены. Канал выпуска — только Seagull;
стабильный выпуск для Song не заменяется.
