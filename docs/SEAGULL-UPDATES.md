# Обновления BYD Split · Seagull

Исходная ветка: `seagull`, репозиторий `hix83/BYD-Split`.
GitHub распространяет APK через Releases, поэтому канал ветки выделен
собственными тегами и именами файлов, а не общим `releases/latest`.

- Тег: `seagull-v0.9.2-alpha.9`.
- Версия APK: `0.9.2-seagull-alpha.9`, versionCode 45.
- Файл: `BYD-Split-Seagull-0.9.2-alpha.9.apk`.
- Для следующего выпуска увеличивать versionCode и номер версии.
- Допустимые этапы: `alpha.N`, `beta.N`, `rc.N`; стабильный Seagull:
  тег `seagull-v0.9.2`, версия APK `0.9.2-seagull`.

Обновлятор просматривает опубликованные Releases с пагинацией, выбирает
максимальную версию Seagull, включая prerelease, и игнорирует `v*` Song
и draft. Сравнение учитывает номер alpha/beta/rc: alpha.10 новее alpha.2.
Не завязываться на дату публикации или поле target_commitish: GitHub может
хранить там SHA коммита, а не имя ветки.

APK должен находиться в выбранном релизе, иметь точное имя, тот же packageId,
версию Seagull, больший versionCode и совпадающую подпись. При наличии
GitHub SHA256 digest он проверяется. Сохранённый APK при продолжении
установки также повторно проверяется, чтобы старый пакет Song не прошёл.
Автопроверка — раз в сутки; ручная — в настройках. Установка с подтверждением.

## Публикация

Собирать только из проверенного коммита ветки `seagull`. Перед тегом
проверить ветку, рабочее дерево, сборку, lint и `tools/test_logic.sh`.
Тег должен ссылаться на тот же коммит, из которого собран APK.
Загружать APK с указанным именем и контрольную сумму. Seagull пока
публикуется как prerelease, без замены Latest стабильной версии Song.

Ключ подписи должен оставаться постоянным. Текущая установленная Mac-сборка
подписана локальным ключом; случайная debug-подпись CI или прежний Windows
ключ не подойдут для обновления поверх неё. Ключи не коммитить. При несовпадении
приложение отклонит APK и сохранит установленную версию и настройки.

Выпуск alpha.4 включает проверенные на DiLink 2 исправления карты Навигатора,
ADB Remote, телеметрии и отдельный канал обновлений. Подробности:
[примечания к выпуску](releases/seagull-v0.9.2-alpha.4.md).


Настройка единого ключа на Windows/macOS и проверка подписи alpha.4:
[SEAGULL-SIGNING.md](SEAGULL-SIGNING.md). Для release теперь требуется
общий ключ; при его отсутствии сборка останавливается.


19 октября 2026 владелец запросил новый постоянный релизный ключ.
Он создан, подключён локально, debug/release APK с ним проверены.
Он отличается от опубликованного alpha.4. Первый переход на этот ключ
не является обычным обновлением поверх старой сборки: миграция данных
и переустановка требуют отдельной работы. Первый выпуск с этим ключом — alpha.5.
Инструкция, приватный архив переноса и публичный отпечаток —
[SEAGULL-SIGNING.md](SEAGULL-SIGNING.md).

В alpha.5 впервые используется постоянный релизный ключ. APK alpha.4 с другой
подписью не обновляется поверх: нужен отдельный перенос данных и переустановка.
Публикация нового файла не меняет ограничения Android по подписи.

Изменения текущего выпуска: [alpha.9](releases/seagull-v0.9.2-alpha.9.md).
